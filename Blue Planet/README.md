# Blue Planet
The Blue Planet has approached us with an urgent need for a database solution to manage
their operations. They want a robust and efficient database that can handle information about wildlife,
exhibits, employees, visitors, and tickets. In addition, they want diagrams showing the structure
and flow of their database.

Task:
The task is to design a database solution that meets the organization’s needs. The solution must include
the following components:

1. Entity-Relationship Diagram (ERD):
Create an ERD that identifies key entities such as Animals, Exhibits, Employees, Visitors, and
Tickets. Outline the relationships between these entities.

2. Class Diagram:
Convert the ERD into a class diagram that represents the classes and their attributes in an object-oriented
context. Also consider methods that can be performed on these classes.

3. Normalization:
Apply normalization principles to ensure that your database is in at least third normal form. This should
include splitting tables and creating foreign keys.

4. Database Flowchart:
Create a flowchart showing how data moves through the system. This should include steps such as
creating new animals, exhibits, and tickets, as well as the relationships that arise.

5. Topological Diagram:
Create a topological diagram to represent the physical or logical structure of your database. This may
include servers, clients, and database access methods.
